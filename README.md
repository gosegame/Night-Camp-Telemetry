# Night Camp Telemetry (Chrome Extension)

**Night Camp Telemetry** คือส่วนขยายเบราว์เซอร์ (Chrome Extension Manifest V3) แบบ **Read-Only 100%** สำหรับเกม [Night Camp Online](https://play.nightcamp.app/?online) เพื่อใช้วัดประสิทธิภาพการต่อสู้, แยกแหล่งที่มาของดาเมจรายสกิลและรูน, ติดตาม Base/Job EXP, คำนวณความคุ้มค่าค่ายา/กำไรสุทธิแบบ Season 2 และเปรียบเทียบ Build A/B แบบเรียลไทม์ผ่าน **Chrome Side Panel** หรือหน้าต่าง **Popout** โดยไม่แทรก UI ใดๆ ทับหน้าจอเกม

---

## ความสามารถหลัก (แบ่งตาม 5 แท็บ)

### 1. Overview (ภาพรวม & EXP)
- **KPI Strip ด้านบน:** ดูค่าหลักได้ตลอดเวลาไม่ว่าจะอยู่แท็บไหน — `DPS` (เลือกสลับระหว่าง `Elapsed DPS` ตลอดรอบ หรือ `Active DPS` เฉพาะตอนสู้), `Crit%`, `EXP/m (B/J)` แยกสี **Base EXP สีเหลือง** และ **Job EXP สีเขียว**, `Taken/s` และกำไรสุทธิ `Net c/h` พร้อมสถานะ `RTT`
- **Base & Job EXP Progress:** แสดงเปอร์เซ็นต์ EXP ปัจจุบัน, EXP ที่ได้ในรอบนี้, อัตราต่อชั่วโมง/นาที และเวลาประมาณการเลเวลอัปทั้ง Base Lv และ Job Lv
- **Live DPS / Damage Taken (120s):** กราฟเส้นสดย้อนหลัง 120 วินาที เทียบดาเมจที่ทำได้กับดาเมจที่โดน
- **Damage Source Composition & Top Skills:** แถบสรุปสัดส่วนแหล่งที่มาดาเมจรวมและรายการสกิล/รูนที่ทำดาเมจสูงสุด

### 2. Skills & Runes (เจาะลึกสกิล & รูน)
- **กราฟแท่งหลายสีแยกแหล่งที่มา (Stacked Bar):** ในแต่ละสกิลจะแบ่งสีให้เห็นชัดว่าดาเมจมาจากส่วนไหนบ้าง:
  - 🔵 **สกิลเอง** (`skill`)
  - 🟠 **รูน Proc** (`runeProc` — ดาเมจจริงของรูนติดผล/Auto-Spell)
  - 🟡 **รูนตัวคูณ** (`runeMod` — ค่าประมาณ `~est` จากตัวคูณของรูนที่ใส่ในสกิล)
  - 🟣 **การ์ด** (`card` — แยกให้ดูทั้ง `จริง` และ `~est`)
  - 🩷 **อาวุธ/เกียร์** (`gear`)
  - 🟢 **DoT** (`dot` — เผา/พิษต่อเนื่อง)
- **ค้นหา & เรียงลำดับ:** ค้นหาชื่อสกิลหรือรูน พร้อมเรียงตาม `DMG`, `DPS`, `Hits`, `Crit%` หรือ `Avg` และกดกางดูรูนที่ฝังอยู่ในแต่ละสกิล
- **All Runes Impact Summary:** สรุปผลรวมรูนทุกเม็ด โดยระบุชัดเจนว่ารายการไหนเป็น **Exact** (ดาเมจจริงที่เซิร์ฟเวอร์รายงาน) หรือ **~Est** (ค่าประมาณจากตัวคูณเพราะเซิร์ฟเวอร์ไม่แยกเลขย่อยส่งมา)

### 3. Elements & Mobs (ธาตุ, เกราะ & มอนสเตอร์)
- **9 Elements Breakdown & Elemental Reactions:** แยกดาเมจครบ 9 ธาตุ พร้อมนับจำนวนครั้งที่จุดชนวนปฏิกิริยาธาตุทั้ง 8 แบบ (เช่น ไอน้ำระเบิด, ไฟฟ้าช็อตน้ำแข็ง, โอเวอร์โหลด, พิษลุกไหม้, ไฟลามทุ่ง, ชำระล้าง, หมอกเดือด, กระแสนำไฟ)
- **Season 2 Armour Type Damage:** แยกดาเมจตามชนิดเกราะมอน (`Heavy`, `Hide`, `Flesh`, `Spirit`)
- **Boss Encounters (Auto-Split):** แยกสถิติเมื่อปะทะบอสให้อัตโนมัติ
- **Per-Monster Breakdown:** แสดงเวลาตายเฉลี่ย (**TTK**) ของมอนแต่ละชนิด เรียงตามดาเมจที่มอนตีเรา เพื่อเช็กตัวอันตรายหรือมอนที่เปลืองยาที่สุด

### 4. Survival & Econ (การเอาตัวรอด & เศรษฐกิจ Season 2)
- **Survival & Healing:** จำนวนครั้งที่ตาย, ดาเมจที่ได้รับ, อัตราการฮีล/รอด
- **Season 2 Economy & Potions:** คิดต้นทุนยาแดง/ยาฟ้า (`red / red_m / red_l / blue / blue_m / blue_l`) ตามราคา Season 2 จริง เทียบกับเหรียญและมูลค่าของดรอป เพื่อดูว่าฟาร์มแมพนี้ **กำไรหรือขาดทุน (Net c/h)**
- **Rare Drops & Dry Streaks:** บันทึกของแรร์/การ์ด/รูนที่ดรอป และระยะห่างตั้งแต่ได้ชิ้นล่าสุด
- **Buff Uptime % & Execution:** เปอร์เซ็นต์เวลาที่มีบัฟสำคัญติดตัวระหว่างสู้ พร้อมข้อมูล `RTT`

### 5. Party & A/B (ปาร์ตี้, เทียบ Build & Export)
- **Party & Nearby DPS Meter:** มิเตอร์เทียบ DPS ของเพื่อนในปาร์ตี้หรือผู้เล่นใกล้เคียง
- **Build A/B Compare:** กด `💾 Save` เพื่อเก็บ Snapshot ไว้เทียบ `Run A` vs `Run B` (เช่น ก่อน–หลังเปลี่ยนรูน อาวุธ หรือย้ายแมพ)
- **Live Combat Log:** บันทึกเหตุการณ์สด กรองดูเฉพาะ `All`, `Runes`, `Taken`, `Drops` หรือ `Err`
- **Export ข้อมูล:** กดปุ่ม `Export ▾` เพื่อดาวน์โหลดรายงานเป็น **`CSV` (Skills & Runes)** หรือ **`JSON` (Full Summary)**
- **Popout Window (`↗`):** แยกหน้าต่าง Telemetry ออกมาลอยอิสระนอก Side Panel

## ออกแบบมาเพื่อเปิดฟาร์ม 24 ชั่วโมง (ประหยัด Resource)

- **เริ่มต้นในโหมดสแตนด์บาย:** หลังโหลดเข้าเกม Extension จะยังไม่ดักจับหรือคำนวณใดๆ จนกว่าคุณจะกด **`▶ เปิด`** ใน Side Panel เอง
- **หยุดเก็บอัตโนมัติใน 5 นาทีเมื่อปิดหน้าต่าง:** หากปิด Side Panel / Popout ทิ้งไว้ครบ **5 นาที** ระบบจะหยุดเก็บข้อมูลให้อัตโนมัติ เพื่อคืน CPU/RAM (**ไม่ตัดและไม่กระทบ WebSocket ของตัวเกม** เปิดเกมฟาร์มต่อได้ปกติ)
- **ควบคุมการใช้หน่วยความจำ (Bounded Buffers):** จำกัดขนาดประวัติ Log/กราฟ 120 วินาที และสะสมสถิติแบบ Aggregate Counter ร่วมกับ `BATCH_FLUSH_MS = 250ms` / `SNAP_THROTTLE_MS = 1000ms` พร้อมหยุดเรนเดอร์หน้าจอทันทีเมื่อพับหน้าต่าง ช่วยให้เปิดทิ้งไว้ตลอดวันได้โดยไม่ค้างหรือกิน RAM บวม

## วิธีติดตั้ง (Google Chrome / Edge / Brave)

> **หมายเหตุ:** แนะนำให้ติดตั้งแบบโฟลเดอร์ (**Load unpacked**) โดยตรง **ไม่ต้องแปลงเป็นไฟล์ `.crx`** เพราะ Chrome บน Windows จะบล็อกไฟล์ `.crx` ที่ไม่ได้โหลดจาก Chrome Web Store ทำให้ติดตั้งไม่ผ่านหรือถูกปิดการใช้งานอัตโนมัติ

1. ดาวน์โหลดหรือ Clone โค้ดให้ได้โฟลเดอร์ `telemetry-ext` ไว้บนเครื่อง (เก็บไว้ในโฟลเดอร์ถาวรที่ไม่ได้ลบทิ้ง)
2. เปิดเบราว์เซอร์แล้วพิมพ์ในช่อง URL ว่า:
   - **Chrome:** `chrome://extensions`
   - **Microsoft Edge:** `edge://extensions`
   - **Brave:** `brave://extensions`
3. เปิดสวิตช์ **Developer mode (โหมดนักพัฒนา)** ที่มุมขวาบน
4. กดปุ่ม **Load unpacked (โหลดส่วนขยายที่แตกไฟล์แล้ว)** แล้วเลือกโฟลเดอร์ `telemetry-ext` (โฟลเดอร์ที่มีไฟล์ `manifest.json` อยู่ด้านใน) *(หรือลากโฟลเดอร์ `telemetry-ext` มาวางในหน้าส่วนขยายได้เลย)*
5. กดไอคอนรูปจิ๊กซอว์ที่แถบเครื่องมือขวาบนของ Chrome แล้วกด **ปักหมุด (Pin)** ที่ **Night Camp Telemetry** เพื่อเรียกใช้งานได้สะดวก

### วิธีอัปเดตเมื่อมีการแก้ไขไฟล์ใหม่
- เปิดหน้า `chrome://extensions` แล้วกดปุ่มรีเฟรช (**↻**) บนการ์ดของ **Night Camp Telemetry** จากนั้นกดรีเฟรชแท็บเกม (`F5`) 1 ครั้ง

## วิธีใช้งาน

1. เปิดเกม `https://play.nightcamp.app/?online` และเข้าตัวละครให้เรียบร้อย
2. คลิกที่ไอคอน **Night Camp Telemetry** บนแถบเครื่องมือเพื่อเปิด **Side Panel** (ถ้าเปิดหลังเข้าเกม ให้กดรีเฟรชแท็บเกม 1 ครั้งเพื่อให้ Hook ทำงาน)
3. เลือกแท็บเกมที่ต้องการจากช่องด้านบน แล้วกด **`▶ เปิด`** (หรือ **`▶ เปิดเก็บข้อมูลแท็บนี้`**) เพื่อเริ่มเก็บสถิติ
4. ปุ่มลัดด้านบนขวา:
   - **`▶ เปิด` / `⏸ หยุด`**: เปิด-ปิดการเก็บข้อมูลของแท็บที่เลือก
   - **`↺` (Reset)**: ล้างสถิติรอบปัจจุบันเพื่อเริ่มจับใหม่ (เช่น หลังย้ายแมพหรือสลับของ)
   - **`💾 Save`**: บันทึก Snapshot รอบปัจจุบันเก็บไว้ใช้เทียบในแท็บ `Party & A/B`
   - **`Export ▾`**: ส่งออกไฟล์ `CSV` (Skills & Runes) หรือ `JSON` (Full Summary)
   - **`↗` (Popout)**: เปิดหน้าต่างแยกอิสระ (ปรับขนาดและย้ายตำแหน่งได้)

## โครงสร้างไฟล์ (สำหรับนักพัฒนา)

| ไฟล์ | หน้าที่ |
|---|---|
| `manifest.json` | กำหนดค่า MV3, สิทธิ์ (`sidePanel`, `tabs`, `storage`, `alarms`) และ Scope เฉพาะ `https://play.nightcamp.app/*` |
| `main-hook.js` | Content script (MAIN world) ดักอ่าน Event / Snapshot ของเกมแบบ Read-Only พร้อม Batch/Throttle |
| `bridge.js` | สะพานส่งข้อมูลระหว่าง `MAIN` world กับ Background Service Worker (`ISOLATED` world) |
| `engine.js` | Telemetry Engine ล้วน (Zero-DOM, Zero-Chrome) คำนวณ DPS, EXP, ธาตุ, รูน, เกราะ, เศรษฐกิจ S2 |
| `background.js` | MV3 Service Worker ดูแล `TelemetryEngine` แยกตามแท็บ, ส่งสรุปเข้า UI และตัวจับเวลาปิดอัตโนมัติ 5 นาที |
| `panel.html` / `panel.css` / `panel.js` | หน้า UI ทั้ง 5 แท็บใน Side Panel และ Popout Window |
| `test-engine.mjs` | ชุดทดสอบ Unit Test สำหรับ `engine.js` |

### การรัน Unit Tests
ต้องติดตั้ง Node.js ก่อน จากนั้นรันคำสั่งในโฟลเดอร์ `telemetry-ext`:

```bash
node --test test-engine.mjs
```

## ความปลอดภัยและความเป็นส่วนตัว

- **Read-Only 100%:** Extension นี้อ่านเฉพาะข้อมูลเหตุการณ์/สแนปชอตที่ตัวเกมได้รับอยู่แล้ว ไม่ส่งแพ็กเก็ตใดๆ ไปยัง WebSocket ของเกม ไม่ดัดแปลง DOM หน้าจอเกม และไม่ใช่บอทควบคุมตัวละคร
- **ทำงานเฉพาะหน้าเกม:** สิทธิ์ `host_permissions` และ `content_scripts` จำกัดไว้เฉพาะ `https://play.nightcamp.app/*` เท่านั้น
- **ไม่มีการส่งข้อมูลออกนอกเครื่อง:** ข้อมูลทั้งหมดประมวลผลในเบราว์เซอร์ของผู้ใช้เอง ส่วน Snapshot สำหรับเทียบ `Run A/B` เก็บไว้เฉพาะใน `chrome.storage.local` ภายในเครื่องเท่านั้น
